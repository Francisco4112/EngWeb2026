## Resumo
Este trabalho cria um `json-server` com o dataset da escola de música
(`db.json`) e um servidor aplicacional em Node.js que consome essa API e
devolve páginas HTML com tabelas para:
- `/alunos` (listagem de todos os alunos);
- `/cursos` (informação de todos os cursos);
- `/instrumentos` (informação de todos os instrumentos).

Foi seguido o modelo de implementação usado na pasta `Semana3/TP3`.
